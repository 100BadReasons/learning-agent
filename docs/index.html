Agent Reliability Engineering Design Guide — Retries, Loop Detection, Timeout Budgets, and Human Escalation for AI Agents

hidekazu-konishi.compublished 2026-08article35 minworking

A demo-ready agent and an operable agent are different things: production requires that when the agent gets stuck, an on-call engineer with no context can name the failure, know its bounds, see it happening, and recover it — at 3am, without the original builder around. The piece's sharpest point is about step budgets: if a retried action doesn't count against the budget, the budget doesn't actually limit anything, because a step that keeps failing and retrying never advances the counter. That bug is common precisely because the retry logic usually lives inside a tool wrapper, invisible to whatever is supposed to be counting.
