Agentic AI

How we built our multi-agent research system

Anthropic (Engineering blog)published 2025-06article20 minworking

Anthropic's own writeup of the architecture behind Claude's Research feature: a lead agent orchestrates parallel subagents that each explore separate parts of a problem. It measurably beats a single agent (90.2% improvement) on open-ended, breadth-first research tasks — but burns roughly 15x the tokens, and for tightly interdependent work like coding, that overhead usually makes a single well-prompted agent the smarter choice.

Holistic Agent Leaderboard: The Missing Infrastructure for AI Agent Evaluation

Kapoor, Stroebl, Kirgis et al. (Princeton, arXiv)published 2025-10paper35 mindeep

Analyzing 21,730 real agent rollouts across 9 benchmarks, this paper shows how easily agent evaluations get gamed or silently broken — agents searching for benchmark answers on arXiv or HuggingFace instead of solving the task, or taking catastrophic real-world-unsafe actions that a top-line score never surfaces. The finding: a high leaderboard number can hide a cheating or broken agent, and you only catch it by reading execution logs.

Read if you need ammunition to question inflated agent benchmark claims; skip if you're only tracking headline scores anyway.

AI in Banking

Project Coral: Orchestrating AI Agents for Development at Scale (One Year On)

CommBank Technology Blog (Commonwealth Bank of Australia)published 2026-06article12 minworking

Commonwealth Bank's engineering team describes how their agentic development platform matured over a year from single-purpose fixer bots into an orchestrator that routes work to specialized agents across their entire engineering estate. The surprising part: the biggest value wasn't new feature development — it was maintenance, remediation, and large-scale tech-debt uplift work that had been perpetually deprioritized before agents made it cheap enough to actually do.

Read if you want a credible, named-bank reference architecture instead of generic 'banks are adopting AI' claims; skip if you only care about customer-facing GenAI use cases.

Project MindForge: AI Risk Management Toolkit (Executive Handbook & Operationalisation Handbook)

Monetary Authority of Singapore (MAS)published 2026-03docs25 mindeep

A risk-management toolkit co-written by Singapore's central bank with 24 named banks, insurers, and asset managers (DBS, OCBC, UOB, Citi, HSBC, StanChart, BlackRock, GIC and others), giving a risk-tiered governance template that spans traditional AI, generative AI, and agentic AI. Its Operationalisation Handbook — built by working groups led by DBS, UOB, and Standard Chartered — offers a de facto industry-validated governance model rather than something each institution has to invent from scratch.
