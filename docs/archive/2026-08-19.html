Agentic AI

AgentAtlas: Beyond Outcome Leaderboards for LLM Agents

arXiv (Parsa Mazaheri, Kasra Mazaheri — UC Santa Cruz, MIT)published 2026-05paper35 minworking

Most agent benchmarks report a single pass/fail number, which hides the difference between an agent that succeeded by being reckless and one that succeeded by handling uncertainty well. This paper proposes scoring agents on their control decisions too — whether they acted, asked for clarification, refused, stopped, confirmed, or recovered at the right moments — using a six-way taxonomy instead of a binary outcome. The point is that two agents with identical success rates can have wildly different risk profiles once you look at how they got there.

Read if you need language to challenge a vendor's benchmark slide; skip if you just want a deployment story.

Beyond Accuracy: A Multi-Dimensional Framework for Evaluating Enterprise Agentic AI Systems

arXiv (Sushant Mehta)published 2025-11paper30 minworking

An agent that scores 60% accuracy on a single run can drop to 25% when you require it to get the same answer consistently across eight runs — meaning a one-shot demo score tells you almost nothing about production reliability. The paper also finds that agents tuned purely for accuracy end up 4.4 to 10.8 times more expensive to run than cost-aware alternatives with similar performance. Together these findings argue that accuracy-only evaluation systematically misleads buyers on both reliability and cost.

Read if you're evaluating any agent pitch on a single accuracy number; skip if you already discount demo scores heavily.

AI in Banking

CommBank develops AI agent that spots new fraud and helps build defences

Commonwealth Bank of Australia (newsroom)published 2026-04article6 minworking

Commonwealth Bank built its own fraud-detection agent in three months, in-house, on Snowflake and its cloud-based core banking platform, and now monitors more than 80 million signals a day with it. The bank credits it with cutting fraud losses over 20% in the first half of FY26 and says it generated or updated three-quarters of the bank's card fraud rules — but every rule suggestion still goes through human review before it goes live. It's a rare disclosure of build timeline, scale, and results from a tier-1 bank rather than a vendor case study.

Read if you're grounding a fraud/AML pitch in a real bank's numbers; skip if you only need vendor-agnostic theory.

Devin's 2025 Performance Review: Learnings From 18 Months of Agents At Work

Cognitionpublished 2025-11article12 minworking

Cognition's own retrospective on 18 months of Devin deployments — including at Goldman Sachs, Santander and Nubank — describes an agent that reads and understands a codebase like a senior engineer but executes changes like a junior one. It's most reliable on tasks with clear upfront requirements and a verifiable outcome, roughly equivalent to 4-8 hours of junior-engineer work, and least reliable on ambiguous or judgment-heavy work. That's a usefully honest scoping line for where an autonomous coding agent belongs in a bank's legacy modernization work — and where it doesn't.

Read if you're scoping autonomous coding agents for bank engineering leadership; skip if coding agents aren't in your patch.
