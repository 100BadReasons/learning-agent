Agentic AI

AgentRx: Diagnosing AI Agent Failures from Execution Trajectories

Microsoft Research (arXiv)published 2026-02paper35 minworking

Researchers show agent failures can be automatically traced to the single step where things went wrong, by generating expected-behavior rules from the tools an agent uses and checking the agent's actual run against them step by step. The break gets sorted into one of nine recurring failure types — things like the agent abandoning its own plan versus the agent fabricating information it never actually retrieved. That turns 'the AI made a mistake' into a specific, checkable diagnosis instead of a shrug.

Read if you need precise language for why an agent failed in a customer demo or pilot; skip if you only need the headline that failures happen.

Architecting Resilient LLM Agents: A Guide to Secure Plan-then-Execute Implementations

arXiv (Del Rosario, Krawiecka, Schroeder de Witt)published 2025-09paper30 minworking

This is a hands-on blueprint for building agents where planning and execution are strictly separated, so a compromised or manipulated input can't easily hijack what the agent actually does — a structural defense against prompt injection, not just a prompting trick. It includes working implementations across three major agent frameworks. The authors are clear that this architecture alone isn't enough: it has to be paired with tightly scoped tool permissions and sandboxed execution to actually hold up.

Read if you talk to technical buyers about agent security architecture; skip if your conversations stay at the business-outcome level.

AI in Banking

NatWest inks AI deal for trade finance

Computer Weeklypublished 2026-05article5 minworking

NatWest has signed on to use Cleareye.ai's ClearTrade platform to automate compliance checks in trade finance — the document-heavy, rules-bound process of verifying transactions against anti-money-laundering and international trade rules. Lloyds made the same move with the same vendor back in 2024, so this isn't a one-off pilot; it's a vendor repeating a proven deal across competing UK banks. It's a sign that bank AI spend is shifting from customer-facing chatbots toward unglamorous, regulation-heavy back-office work.

Read if you sell into UK or trade-finance-adjacent banking functions; skip if your accounts don't touch trade operations.

Artificial Intelligence in the Financial System (FSOC AI Roundtable speech)

Federal Reserve Board (Vice Chair for Supervision Michelle Bowman)published 2026-05article12 minworking

The Fed's top bank supervisor explains that the 2026 overhaul of model risk management guidance deliberately excludes generative and agentic AI from formal scope — not an oversight, but a correction, because supervisors had been stretching a 2011 framework built for statistical models onto tools it was never designed to govern. A joint request for information from the Fed, OCC, and FDIC on AI-specific model risk is coming next, meaning the current gap is a pause, not a permanent exemption.

Read if you engage with a bank's risk, compliance, or model-governance teams; skip if your deals never touch that layer.
