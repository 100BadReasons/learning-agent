Agentic AI

Context Engineering for AI Agents: Lessons from Building Manus

Manus (Yichao 'Peak' Ji)published 2025-07article25 minworking

The biggest lever in a production agent isn't model choice or prompt cleverness — it's how much of the growing context window can be reused from cache step to step, since cached tokens can cost roughly 10x less than fresh ones and agent context balloons with every action while the model's actual output stays short. The piece also argues for masking tools rather than removing them mid-task and for deliberately leaving failed attempts in context so the model doesn't repeat them.

Read if you want concrete, engineer-level reasons agents behave the way they do; skip if you only need the high-level pitch.

arXiv (Xu et al.)published 2026-03paper50 mindeep

This survey traces agent tool-use research from models picking one correct API call to orchestrating many tools across long sequences of steps, with safety and cost constraints now built into the evaluation. It organizes the field around six dimensions — including planning/execution and safety/control — that double as a checklist for telling a genuine multi-step agent architecture from a chatbot with a plugin attached.

Introducing Gemini Enterprise for Financial Services
