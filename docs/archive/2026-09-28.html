Today pairs the technical grammar of agents (how they're built, how their memory actually works) with two live bank deployments that both put an agent between the client and the core system while keeping a human as the accountable party of last resort.

Agentic AI

CS329Z: Engineering AI Agents

Stanford University (Diyi Yang, Michael Ryan, John Yang)published 2026-09course40 minworking

This is a graduate course that refuses to let students touch an agent framework until they've built one by hand: the first assignment requires the agent loop, tool calls, and retrieval to be built directly on a raw chat-completion API. The reasoning is that frameworks hide exactly the decisions that determine whether an agent works in production, and you can't evaluate what's hidden until you've built it yourself. The rest of the course is organized around the three things that actually break agent projects — breaking a task down correctly, curating the data an agent learns from, and building evaluations that catch failure before a customer does.

Read if you want the vocabulary to tell a real agent architecture from a framework demo; skip if you just need the news.

The Missing Memory Hierarchy: Demand Paging for LLM Context Windows

arXiv (Tony Mason)published 2026-03paper25 minworking

The paper argues that treating an AI agent's context window as its entire memory — rather than as a fast, small cache sitting on top of a larger storage layer — is the reason long-running agents get slow, expensive, and forgetful. Measuring real production sessions, the authors found 21.8% of context space was wasted on structural overhead rather than useful information. Adding a transparent 'paging' layer that moves information in and out of the window as needed cut context consumption by up to 93% with no change the model could detect.

Read if you need a solid, non-hand-wavy answer to 'why does this agent get worse the longer it runs'; skip if you're not fielding that question yet.

AI in Banking

Morgan Stanley will soon open its trillion-dollar wealth management funnel to AI agents

CNBCpublished 2026-06article8 minworking

Morgan Stanley is opening its wealth-management platforms so that corporate clients' own AI agents can pull data and instructions directly from systems like ShareWorks and Equity Edge, using an open standard for connecting AI models to data sources — instead of routing everything through the human-facing software interface. That flips the usual order: the screen built for people becomes a fallback, not the front door. It's also a deliberate contrast with JPMorgan and Goldman Sachs, who are running agents internally rather than letting outside agents reach into their systems.

Read if you sell into banks and need a real example of the 'agent talks to system directly' pattern; skip if you only track internal-copilot use cases.

Deutsche Bank Private Bank launches Agentic AI solution for Source of Wealth KYC processes

Deutsche Bankpublished 2026-09article4 minintro

Deutsche Bank's private bank has put an agentic AI system into one of the most regulator-sensitive workflows in banking: verifying a client's source of wealth. The system researches and assembles documentation from case files and approved external sources, flags gaps or inconsistencies, and prepares the assessment — but stops short of deciding, because a person still reviews and signs off. The bank was explicit on this point: tasks can be automated, but accountability stays with people.

Read if you deal with compliance or risk teams asking who's liable when an agent touches KYC; skip if that's not your buyer.
