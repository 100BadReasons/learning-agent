How Coding Agents Fail Their Users: A Large-Scale Analysis of Developer-Agent Misalignment in 20,574 Real-World Sessions

Tang, Chen, Xu, Shi, Huang, McMillan, Dong, Li (Notre Dame / Vanderbilt / Google)published 2026-05paper25 minworking

Researchers analyzed 20,574 real-world coding-agent sessions to see how developers and agents actually break down when working together. Most failures were low-stakes - wasted effort or eroded trust rather than broken code - but the striking finding is self-awareness: in the vast majority of cases (over 91%) the agent only corrected course after the developer explicitly pushed back, rather than catching its own error. In other words, these tools are already reasonably competent at producing output, but they are still bad at knowing when that output is wrong.

Read if you're positioning coding agents (or any autonomous AI tool) to technical buyers and need grounded language about where human oversight is still doing the real work; skip if you only need a one-line talking point.
